# Arpita Gupta — Portfolio

Modern, high-performance developer portfolio built with clean semantic HTML5, modern vanilla CSS, and vanilla JavaScript.

- **Live URL**: https://guptaarpita-portfolio.vercel.app/
- **Portfolio / Year**: 2026
- **Architecture**: Lightweight single-page application (zero npm dependencies, zero build step)

## Features
- **Hero Section**: 100vh viewport-calibrated design with animated orbital lettermark, multi-axis dashed rings, and real-time status telemetry cards.
- **About**: Split 2-column narrative layout highlighting systems architecture, university background (UMIT Mumbai '27, 8.91 CGPA), and engineering mindset.
- **Experience**: Timeline detailing roles at Mercor (Odin Writer), Deutsche Bank (AI Engineer Intern), and BuzzGeeks (Technical Developer Intern).
- **Projects**: Featured dual-column IDE showcase for Market Risk Dual-RAG Assistant, along with full-stack enterprise applications.
- **Achievements**: Highlight cards for Deutsche Bank Global Hackathon, Google Summer of Code (OSGeo), SpaceSpirit, and DevCon.
- **Toolkit**: Categorized pill taxonomy for Languages, Frameworks & Platforms, AI/ML & Agent Orchestration, and Tools/Databases.
- **Let's Talk**: Clean interaction section with contact channels (Email, LinkedIn, LeetCode, GitHub).

## Local Development
Run any static file server:
```bash
# Python
python -m http.server 3000

# or Node.js / npx
npx serve .
```
Open `http://localhost:3000` in your browser.
