A modern, high-performance developer portfolio built with semantic HTML5, modern vanilla CSS, and lightweight vanilla JavaScript. Designed around a dark, builder-first aesthetic inspired by systems engineering, agentic AI workflows, and minimalist developer tools.

🌐 **Live URL**: [https://guptaarpita-portfolio.vercel.app/)

---

## ⚡ Tech Stack & Architecture

- **Core Technologies**: HTML5, Modern CSS3 (CSS Variables, Grid, Flexbox, Keyframe Animations), Vanilla JavaScript (ES6+).
- **Typography**: `Outfit` (Headlines & Display), `Inter` (Body & Narrative), `JetBrains Mono` / `Fira Code` (Monospace & Telemetry), `Unbounded` (Orb Lettermark).
- **Design Philosophy**: Zero bloated frameworks, zero npm dependencies, zero build step. Instant first-paint load times (<100ms) with pure browser-native execution.
- **Hosting & CI/CD**: GitHub Pages via automated GitHub Actions workflow (`.github/workflows/deploy.yml`).

## 🛠️ Local Development

Clone the repository and launch any local static server:

```bash
# 1. Clone repository
git clone https://github.com/guptaarpita/arpitaguptaportfolio.git

# 2. Navigate to project folder
cd arpitaguptaportfolio

# 3. Start local server
# Using Python:
python -m http.server 3000

# Or using Node.js / npx:
npx serve .
```

Open `http://localhost:3000` in your web browser.
